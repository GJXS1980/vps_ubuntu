# 用户手册
1. 在本地平台打开“注册账号”。用户名、邮箱各自唯一。密码为 12 至 128 个字符，至少含六种不同字符。邀请模式需要一次性邀请码。
2. 默认进入等待审核页，管理员批准后再登录。登录普通账号可留空动态验证码。
3. “我的设备”显示账号状态、在线摘要、配额和最近领取时间。选择 VPS、填写设备名称并提交申请。缺少 VPS 时联系管理员配置。等待任务完成后刷新。
4. 打开设备详情，核对所属节点、分配地址、最近采样时间、握手和流量。在线状态基于 VPS 的握手窗口，未采样或查询失败时数值可能为空。
5. 选择 global 或 proxy 的文件或二维码。使用 WireGuard 客户端从文件导入，手机也可扫描另一台可信设备上的二维码。两种模式共享密钥，同一时刻只启用一个。proxy 需在使用代理的应用中设置 SOCKS5 10.66.77.1:1080。
6. 二维码和文件含私钥与 PSK。请勿共享、截图上传或发到群聊。若泄露，联系管理员立即停用或轮换。轮换后刷新设备详情，重新导入新配置。
7. “个人与安全”支持更新邮箱、验证邮箱、修改密码、撤销全部会话。忘记密码时使用已验证邮箱接收重置码；邮件未启用时联系本地管理员。
