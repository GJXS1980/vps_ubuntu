# 限制与待现场验证项
- 开发环境为 Windows，具有 Python、Node、Chrome 和 Git Bash；未连接生产 VPS，无 Docker Engine、已安装 WSL Linux 发行版或真实 WireGuard 接口。Compose 首装/重装、systemd/sudoers 在 Ubuntu 上运行、真实接口同步与隧道流量待按验收手册执行。
- 邮件接口用模拟投递验证。真实 SMTP 登陆、证书信任、垃圾邮件策略和互联网收信取决于部署方。
- 原协议硬编码双栈、UDP 51820、global DNS 与 proxy 路由。全网段共 253 个地址；为避开旧 user01 与管理地址，平台只新分配 .4 至 .254，最多 251 个，历史资源会进一步降低可用量。每个 VPS 需独立管理身份和与本地可路由且无冲突的管理网段。
- 服务采用 SQLite 单写者。为使领取与变更有明确先后，部分操作在本地写事务中等待远端，VPS 慢或多个节点不可达时会增加其他写请求的延迟。资源清单采用浏览器端分页；管理日志按最新 500 条加载。高并发与长期容量尚未压测。
- 远端回执随旧状态保留；长时间运行会增加旧 JSON 的大小。不要手工删除幂等记录或拷贝其他 VPS 的状态覆盖历史。突然断电后的文件系统持久性、外部手工篡改与自定义旧 CLI 需另做现场验证。
- 本地离线或管理网络断开时，已导入的 VPN 配置仍可连接到 VPS，直到停用或轮换实际同步成功。在线状态是最近一次采样，VPS 离线时应同时查看采样时间与健康告警。
- 本地备份不回滚 VPS 的真实密钥、历史 Peer、操作账本或流量。数据库恢复后可能出现远端外部资源和本地 missing 记录，应由管理员核对后决定。现有 Peer 接管会保留原持有者已领取的配置。
- 本地自签证书需要在可信设备上手动建立信任。管理 CA 按链路生成，换证时需协调替换两端证书，保留旧凭据至新握手验收。项目不自动修改云安全组，也不自动发布公网域名或申请公信证书。
